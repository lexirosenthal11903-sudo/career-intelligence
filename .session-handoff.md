# Career Intelligence — Session Handoff (updated 2026-06-29)

## What THIS session shipped — the "engaged, focused mentor" (commit `fbd4381`, pushed to staging)

The advisor now behaves like a present mentor over time, not a chatbot that waits to be asked. Grilled +
research-grounded, then built on Opus. Two behaviours, one loop (holding a thread CREATES the parked thread the
return-opener later reopens).

1. **Proactive check-in on return.** On a *meaningful return* (new calendar day or ~6h+ gap via
   `conversations.updated_at`, NOT every login, suppressed if the user's already typing) the advisor speaks first,
   reads the recent transcript + durable open threads, and picks up the SINGLE most significant unresolved one —
   never a backlog, never mentions the gap. Root cause was two-fold and both are fixed: `useArloChat` now fires a
   resume-opener, and `chat/route.ts`'s initiate path now actually receives the transcript (it only had profile
   facts before — that's why it never saw the visa thread).
2. **Hold the thread.** On a mid-task topic-switch the advisor holds *relationally*: acknowledge → offer a choice
   → follow their lead; reads avoidance-vs-need; closes on a specific next action; follows up "how did it go?" not
   "did you do it?".

**New storage:** `profiles.data.openThreads[]` (invisible, clearable, NO migration — same jsonb) +
`addOpenThread`/`resolveOpenThread` (`lib/profile.ts`) + two advisor tools `note_open_thread`/`resolve_open_thread`.
**Docs:** behaviour in `ADVISOR_PERSONA.md` → "The engaged, focused mentor"; spec in
`brainstorms/engaged-focused-mentor.md`; research in `research/task-focus-and-switching-research.md`;
`FEATURE-ROADMAP.md` + `REBUILD.md` marked shipped.

**Verified:** tsc + lint clean; 3 new eval personas; `eval:advisor` green on the final prompt. Every inspected
advisor reply obeyed the rules. ⚠️ **Eval gotcha learned:** the eval counts transient `fetch failed` network
errors as "hard failures" (same counter as real rule breaks), and piping it through `tail` masks the exit code +
truncates the failures — inspect the actual `✗` lines before trusting the count. Future eval-infra fix: separate
API-failure from rule-failure.

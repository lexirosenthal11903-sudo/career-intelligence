  removing them. **Grill once per batch upfront → build the whole batch autonomously (self-verify each, push

- **Guardrails:** one KIND of work per batch (never mix build with voice/copy fine-tuning); ~4–6 related items;
  milestone-test once; build independent slices in parallel with subagents.

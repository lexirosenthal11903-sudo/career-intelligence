## The big root cause found (and the plan for it)
**Sign-up loses the input conversation + CV.** Root cause (full writeup in AUDIT "Live-test feedback" A/B):
on in-place sign-up the advisor builds its context before the pre-signup data is saved to the account, and
the result save is gated on a variant that path never hits. The advisor opens against an empty account and
treats a just-signed-up user as a stranger.

**The fix is the anonymous-auth migration** — `docs/plans/anonymous-auth-migration.md` (verified vs Supabase
docs, awaiting Lexi's approval). Standard pattern: a real anonymous account from first landing, email
attached in place via OTP on sign-up. Removes the brittle sessionStorage bridge, keeps the no-commitment
flow, fixes the email-confirmation case too.
